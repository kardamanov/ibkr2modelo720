# ibkr2modelo720

Генератор файла Modelo 720 (AEAT) из CSV-выгрузки Interactive Brokers с терминальным интерфейсом.

## Что делает

Конвертирует CSV-выгрузку портфеля из Interactive Brokers в текстовый файл фиксированной ширины,
соответствующий [спецификации Modelo 720](https://sede.agenciatributaria.gob.es/static_files/Sede/Disenyo_registro/DR_Resto_Mod/archivos/modelo_720.pdf),
опубликованной Agencia Tributaria (AEAT) Испании.

Сгенерированный файл можно загрузить напрямую в Sede Electrónica AEAT для подачи декларации.

## Возможности

- Терминальный интерфейс (Textual) для ввода данных декларанта
- Парсинг CSV из IBKR с автоматическим объединением дубликатов ISIN
- Получение курса EUR/USD с API Европейского центрального банка (с возможностью ручного ввода)
- Генерация записей Tipo 1 (декларант) и Tipo 2 (детали актива)
- Выходной файл: 500 байт/строка, ISO-8859-1, разделитель строк CRLF
- Экран предпросмотра с таблицей позиций и итогами в EUR перед сохранением

## Требования

- Python >= 3.14
- [uv](https://docs.astral.sh/uv/)

## Использование

```bash
uv run python -m ibkr2modelo720
```

Терминальный интерфейс проведёт через ввод:
- NIE/NIF, имя, телефон
- Фискальный год
- Путь к CSV-файлу IBKR
- Курс EUR/USD (автоматическое получение с ECB или ручной ввод)
- Происхождение активов (новые / ранее декларированные)
- Путь к выходному файлу

## Формат входного CSV

Ожидаемый CSV из IBKR содержит следующие колонки:

```
ISIN,Description,Quantity,CurrencyPrimary,PositionValue,AssetClass
```

Файл может содержать повторяющиеся строки заголовков — они пропускаются автоматически.
Позиции с одинаковым ISIN объединяются (количество и стоимость суммируются).

## Спецификация Modelo 720

Выходной файл соответствует *Diseño de Registro*, опубликованному AEAT:
- Тип записи 1: сводка декларанта (1 на файл)
- Тип записи 2: детали актива (1 на уникальный ISIN)
- Каждая запись — ровно 500 символов, дополненная пробелами
- Кодировка: ISO-8859-1
- Разделитель строк: CRLF

Сейчас поддерживается тип актива **V** (valores — ценные бумаги) с подтипом **1**
(участие в капитале юридического лица). Другие типы активов (C — счета, I — ИИК,
S — страхование, B — недвижимость) не реализованы.
